# Site oficial do ProxyEdu

Esta pasta contém uma landing page estática pronta para GitHub Pages.

## Publicação

1. Extraia o ZIP.
2. Envie para a raiz do repositório:
   - index.html
   - style.css
   - script.js
   - pasta assets
3. Confirme o commit.
4. Aguarde o GitHub Pages atualizar.

Endereço esperado:
https://marcosbravin.github.io/ProxyEdu/

Importante: envie o conteúdo da pasta, não apenas o arquivo ZIP.
