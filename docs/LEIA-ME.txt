PROXYEDU - SITE PARA GITHUB PAGES

1. Extraia este arquivo ZIP.
2. Envie index.html, style.css, script.js e a pasta assets para a RAIZ do repositório ProxyEdu.
3. Não envie a pasta proxyedu-site inteira; envie os arquivos que estão dentro dela.
4. No GitHub, confirme em Settings > Pages:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
5. Após o commit, acesse:
   https://marcosbravin.github.io/ProxyEdu/

Observação: se já existir um index.html na raiz, substitua-o pelo novo arquivo.
