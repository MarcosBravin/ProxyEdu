Não há banner porque não há cookies opcionais próprios

O código deste site não cria cookies, não usa localStorage, não incorpora publicidade e não carrega Google Analytics, Meta Pixel ou ferramenta equivalente. Se isso mudar, a política e o mecanismo de escolha deverão ser atualizados antes da ativação.

1. O que são cookies

Cookies são pequenos registros que um site pode armazenar no navegador para manter sessão, preferências, segurança, medição ou publicidade. Tecnologias semelhantes incluem armazenamento local, pixels e identificadores de dispositivo.

3. Hospedagem e API do GitHub

O site é entregue pelo GitHub Pages. A página inicial consulta api.github.com para obter somente a release estável mais recente; as páginas jurídicas não fazem essa consulta. Ao receber uma requisição, o GitHub pode processar endereço IP, data e hora, agente de usuário e outros metadados técnicos segundo suas próprias práticas.

O site não controla os cookies ou logs de infraestrutura definidos pelo GitHub. Consulte a Declaração de Privacidade do GitHub ↗ e a política de cookies do GitHub ↗.

4. Downloads e links externos

Ao abrir o repositório, uma release, documento legal oficial ou qualquer outro domínio, o usuário deixa este site e passa a se sujeitar às políticas do destino. Links externos são identificados com o símbolo ↗ quando abrem nova aba.

Bloquear cookies nas configurações do navegador não afeta o conteúdo estático principal, mas pode afetar recursos do GitHub após sair desta página.

5. Esta política não descreve o painel local

O dashboard instalado na escola é uma aplicação separada. Credenciais, cabeçalhos de autenticação, logs e dados de navegação do ProxyEdu Server são tratados na infraestrutura institucional e estão descritos na Política de Privacidade. Eles não devem ser confundidos com cookies deste site público.

6. Alterações

Se forem adicionados analytics, vídeo incorporado, formulário, atendimento, preferências ou qualquer tecnologia opcional de rastreamento, esta página deverá informar fornecedor, finalidade, duração e base aplicável, além de oferecer escolha antes da ativação quando exigido.

A versão e a data desta política serão atualizadas junto com a mudança técnica correspondente.
