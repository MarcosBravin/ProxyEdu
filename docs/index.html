A internet da escola, sob controle.

O controle acontece onde a rede acontece.

Os Clients identificam cada instalação e mantêm contato com o Server da escola. O Server concentra o proxy, a autorização e o estado dos dispositivos.

01

Instale o Server

Defina a máquina central, crie o acesso administrativo inicial e configure a rede da instituição.

02

Conecte os Clients

Cada computador recebe uma identidade persistente. Reconexões e mudanças de IP não criam novas vagas.

03

Administre o acesso

Acompanhe dispositivos e libere vagas quando uma instalação deixa definitivamente de fazer parte da rede.
