1. Uso atual

O site público do ProxyEdu é estático e não depende de cookies publicitários para funcionar. O formulário de avaliação envia os dados informados diretamente ao endpoint da BravinTech e não armazena a credencial ou conteúdo do pedido no navegador após o envio.

2. Conteúdo e infraestrutura de terceiros

A página de releases consulta a API pública do GitHub para exibir versões e downloads. A infraestrutura de DNS, proteção e hospedagem pode processar registros técnicos, como endereço IP, data, agente de usuário e eventos de segurança, conforme as políticas dos respectivos provedores. Fontes web podem ser carregadas pelo Google Fonts.

3. Controle e mudanças

Seu navegador permite bloquear ou eliminar cookies e dados locais. Como a funcionalidade central deste site não exige cookies de preferência ou publicidade, o bloqueio não deve impedir o acesso às páginas. Se futuras funcionalidades adicionarem tecnologias não essenciais, esta política e os controles de consentimento serão revistos antes da ativação.

Para saber como dados pessoais são tratados, consulte o Aviso de Privacidade.
